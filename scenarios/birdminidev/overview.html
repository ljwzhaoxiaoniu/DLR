TSM 建模实例化 · 一道题看三级语义

以 debit_card_specializing q1490（「How many percent of LAM customer consumed more than 46.73?」· 数据集缺陷 · 难题 · SOP 裁定 🔁）为例：L3 定口径 → L2 给通用规则 → L1 指出实体与列语义 → 按 SOP 口径落成 SQL → 判定。

L3 · SOP业务逻辑级 · 题面措辞逐字命中一节 → 定口径
  • Expected 98.3871；类型 = 数据集问题 · 难题（gold 自身按 record 级公式，存在口径缺陷——SOP 裁定单独计数不并入正确）。
  • 「"Percent of customers" is counted per customer, not per customer-month record. One customer = one unit in both the numerator and the denominator, matched to the same caliber: Numerator — customers whose total consumption (added up across their monthly figures) exceeds the threshold; Denominator — all customers of that segment (customers with no consumption records count too). A customer list built by matching against the consumption records alone silently drops them and shrinks the denominator. Do not copy a record-level formula if you retrieved one.」
L2 · CONSENSUS领域共识 · 通用规则 → 定怎么算
  • 「Percentage Calculation: To calculate the percentage of a part relative to a total, use (Count of Part / Total Count) * 100%. When computing customer-level percentages, the denominator must include ALL customers in the target group — count from the customer master table directly or use LEFT JOIN, never INNER JOIN (which silently drops customers without matching records). When the condition involves a threshold on an aggregated measure (e.g., 'consumed more than X'), first compute the per-customer aggregate via SUM with GROUP BY, then apply the threshold on the aggregated result — do not compare individual rows to the threshold before aggregation.」
  • 来源 qids：1490 · 1493 · 1525 · 1481（规则自这批题归纳）
L1 · DLR数据源级 · 实体 / 列语义 → 给表与列

      CustomerID · Segment（SME=Small Business / LAM=Local / KAM=Key Account）· Currency（CZK/EUR）

      A 键 CustomerID ——「全量分母」的落点：从 Customer 主表直取（含无消费记录的客户）

L1 只写实体 / 列语义（schema 级）；口径由 L3 定、算法由 L2 给、取数由 agent 实查落成 SQL。
