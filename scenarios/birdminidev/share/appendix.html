复跑入口

一条命令，自己复核

# 1) 起语义后端（Neo4j + MCP server :28795，幂等）
bash "DSH-based Agent Service/scripts/start_backend.sh"

# 2) 单题
bash "DSH-based Agent Service/dsh_dlr/run_one.sh" <qid> "<question>"

# 3) 批跑 → 判定 → 统计
bash "DSH-based Agent Service/scripts/run_batch.sh" --qids <q1>,<q2> --jobs 3
cd "TSM Core Service"
node bin/tsm.mjs grade --run "<批次目录>"    # → questions.csv + summary.md
node bin/tsm.mjs stats                        # → results/STATS.md + 台账 DETAIL.md
考卷：scenarios/birdminidev/eval/questions.jsonl——500 行 = 题面 + 期望 + 口径来源（74 处缺陷题的答案键取 L3 节口径，其余取 gold）。
台账：DETAIL.md + DETAIL/<库>.md（逐题判定依据与证据）。
完整上手（含 Web 对话与 bundle 安装）见仓库 README。

统计口径与 tsm stats 相同（每题取最新一轮、上中位）；复算脚本见 scenarios/birdminidev/eval/appendix_views.mjs。
