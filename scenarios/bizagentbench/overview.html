TSM 建模实例化 · 一道题看三级语义

以 case_003（九月收款对账 + 公司账户）为例：L3 定打法 → L2 定读法 → L1 给对象 / 记录面 / 关系 → agent 经基准记录与动作工具实查、改状态。

L3 · SOP业务逻辑级 · 题面措辞逐字命中一节 → 定打法
  • 付款方的 dispatch notice 若写明后来追发的 revision，以后版为准；按旧版 advice 做出的分配会在对账时失败。
  • express 行金额逐字对；剩余 gross 只分配给其他合规发票，不得抬高固定行去凑总额。
  • 关账前逐行核对 allocation map 与所用 advice revision——不一致就不关。
L2 · CONSENSUS领域共识 · 读法与口径 → 定怎么读
  • 「A READY remittance advice is authoritative for the revision it describes. Each express designation fixes an amount for the invoice identified by buyer, purchase order and period; an omitted invoice has no fixed clause, not an automatic zero allocation.」
  • 「propose_remittance_advice obtains the advice dispatched by the payer after the remittance trace delay; it does not change cash. If no revision is pending, the trace confirms the current advice. Read the returned advice record rather than assuming its lines.」

这条链 = 三级协作：L3 先定“后版 notice 为准、固定行逐字对、关账前核对”；L2 给 advice 的权威口径与 trace 读法；L1 给出 Remittance → Advice → Allocation 的对象/锚/关系；agent 实查记录后改状态，verifier 从最终世界与审计轨迹判 G/P/F。逐题台账 · 机器可读 ledger
