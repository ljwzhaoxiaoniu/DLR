# Router：[[L2_Line_Loss_Analysis]]
**所属 L1 领域**：[[配网营销领域]]

## 1. 场景定义
- **核心场景**：台区日线损率异常分析、高线损根因追溯。
- **匹配标签**：#线损率突增 #高线损 #数据不一致 #账卡物排查

## 2. 精准匹配特征 (Intent Patterns)
> 当用户查询包含以下业务意图时，应触发精准匹配：
- **特征 A（新投产）**：提及“新投运”、“新改建”、“刚送电”后的线损问题。
- **特征 B（大负荷）**：提及“工业区”、“增容”、“大客户”、“扩容”后的线损跳变。
- **特征 C（存量慢性）**：提及“老旧小区”、“长期高线损”、“找不到原因”的持续异常。

## 3. 典型触发样例 (Calling Samples)
- "新投运的幸福花园台区线损为什么高达 40%？" -> **匹配成功**
- "某工业园区台区本月线损突然从 3% 跳到了 15%。" -> **匹配成功**
- "查一下某台区这个月的线损率。" -> **泛化匹配（进入全场景模式）**
- "怎么给台区充值电费？"-> **匹配失败**

## 4. 约束指令
- 严禁处理任何非“损耗分析”相关的电力业务。
- 若无法判定，请退回 L1 泛化模式。
