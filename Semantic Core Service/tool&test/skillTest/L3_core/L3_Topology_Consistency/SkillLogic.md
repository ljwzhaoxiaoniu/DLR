# Core：[[L3_Topology_Consistency]]

## 一、 专家直觉 (Expert Insight)
当台区出现高线损时，核心怀疑对象是**“拓扑档案错配”**。
* **因果逻辑**：用户物理上消耗了本台区的变压器电量（计入供电），但账本上却把电费交给了别的台区（售电缺失）。
* **判定核心**：不仅要找到“挂错”的人，还要抓到他“挂错”的电量。

## ## 三、 判定规程 (Diagnostic Rules)

### ### 1. 第一步：身份对撞（找“人”）
**操作**：比对 [物理拓扑关系] 与 [用户档案]。
**判定**：若发现用户（如 **YH_9527**）物理归属与逻辑归属不一致，判定为“档案错配”。

### ### 2. 第二步：能量追溯（找“电”）
**操作**：针对上述错配用户，调取其在[[统计日期]]的[[抄见电量]]。
**计算**：汇总所有错配用户的电量总和 `Sum(抄见电量)`。- 
**结论**：若汇总电量>0，则确认命中“拓扑错配导致实物资产流失”。
